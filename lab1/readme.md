## Готовые файлы

В репозитории подготовлены скомпилированные бинарные файлы и отчет:

* `colorPicker` — исполняемый файл для Linux (x86-64);
* `colorPicker.exe` — исполняемый файл для Windows (x86-64);
* `report.pdf` — отчет по лабораторной работе.

## Сборка

Для сборки необходим Go 1.20+ и C-компилятор (gcc/MinGW) для графических библиотек Fyne.

Сборка под Linux:
```bash
go build .
```
Сборка под Windows:
```bash
go build -ldflags -H=windowsgui .
```
