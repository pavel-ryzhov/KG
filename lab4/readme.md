## Структура проекта
* `main.py` — точка входа в приложение.
* `algorithms.py` — чистая математика: коды Сазерленда-Коэна, алгоритм средней точки и Сазерленда-Ходжмана.
* `canvas.py` — кастомный QWidget: координатная сетка с адаптивным шагом, масштабирование (zoom/pan) и отрисовка примитивов.
* `main_window.py` — главное окно: элементы управления, единая кнопка демо и автоопределение формата файлов.

## Установка и запуск

1. **Установите зависимости:**
```bash
pip install PyQt6
```
2. **Запустите приложение:**
```bash
python main.py
```
