## Структура проекта
* `main.py` — точка входа в приложение.
* `algorithms.py` — чистая математика: функции алгоритмов растеризации.
* `canvas.py` — кастомный QWidget: отрисовка сетки, осей и "пикселей".
* `window.py` — главное окно: элементы управления, логика бенчмарка.

## Установка и запуск

1. **Установите зависимости:**
```bash
pip install PyQt6
```
2. **Запустите приложение:**
```bash
python main.py
```
