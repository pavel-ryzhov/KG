## Структура проекта
* `main.py` — точка входа в приложение.
* `main_window.py` — графический интерфейс (PyQt6) и логика взаимодействия.
* `image_processor.py` — алгоритмы обработки изображений (OpenCV).

## Установка и запуск

1. **Установите зависимости:**
```bash
pip install PyQt6 opencv-python numpy
```
2. **Запустите приложение:**
```bash
python main.py
```
